Build the plugin, start the server, open the ports - step by step for your own server.

AlphaThis documentation and the whole system are in active development - behavior may change. Issues

Self-hosting

This page describes how to run SimpleVoiceChatWeb on your own server: build the plugin, open the ports, serve the web client. The web client is a static site and works behind any web server.

The public instance of the project runs on GitHub Pages: the landing page at /, the web client at /app/, and these docs at /docs/.

Ports and firewall

PortProtocolPurpose
24454TCPWebSocket signaling (wss://)
24454UDPSVC voice
443TCP (outbound)PeerJS signaling
# UFW example
ufw allow 25565/tcp   # Minecraft
ufw allow 24454/tcp   # WebSocket signaling
ufw allow 24454/udp   # SVC voice
ufw enable

Tip: Always test ports from an external network
(phone hotspot), not from the server itself!

Environment variables

Every option can be overridden with the SVCWEB_ prefix plus the dotted path in upper case, with dots replaced by underscores:

VariableDescription
SVCWEB_AUTH_JWT_SECRETFixed JWT secret instead of auto-generation
SVCWEB_TLS_KEYSTORE_PASSWORDKeystore password, preferred over the file
